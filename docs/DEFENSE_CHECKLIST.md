# Проверка перед сдачей

- [ ] Docker Desktop запущен; `docker compose up --build -d` поднимает три сервиса.
- [ ] /login, /register, /profile открываются; обновление /profile не даёт 404 Nginx.
- [ ] Регистрация USER, повтор имени/email → понятная ошибка.
- [ ] Неверный пароль → 401 без бесконечных повторов.
- [ ] USER видит список и карточку; кнопок изменения нет; прямой запрос POST/PUT/DELETE → 403.
- [ ] ADMIN создаёт, меняет, удаляет запись без полной перезагрузки.
- [ ] Все поля проходят клиентскую и серверную валидацию.
- [ ] Фильтры каждого поля, направление сортировки и размер страницы работают на сервере.
- [ ] При изменении фильтров page сбрасывается в 0.
- [ ] При удалении последней записи текущей страницы нет зависания на пустой странице.
- [ ] Быстрый поиск: результат старого запроса не перезаписывает новый.
- [ ] Одна ошибка API не выключает дальнейший поиск.
- [ ] Загрузка видна; двойное нажатие «Сохранить» не создаёт два запроса.
- [ ] При истёкшем access выполняется refresh и один повтор.
- [ ] При недействительном refresh открывается вход; после logout нет позднего восстановления сессии.
- [ ] Снятие ADMIN в базе действует со следующего запроса; UI обновляет роль после 403.
- [ ] Остановка backend даёт понятную сетевую/серверную ошибку, а не белую страницу.
- [ ] `npm.cmd test`, `npm.cmd run lint`, `npm.cmd run build` проходят.
- [ ] Backend-тесты проходят на JDK 21+.
- [ ] `.env` не в Git и не в передаваемом архиве; `.env.example` присутствует.
- [ ] Прочитан LAB4_GUIDE.md; могу показать путь запроса и объяснить RxJS своими словами.
