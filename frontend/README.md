# Frontend — Next.js / лабораторная №5

Запуск и настройки: см. корневой `README.md`.

`npm.cmd run dev` — http://localhost:5173, `npm.cmd run build` — production-сборка, `npm.cmd start` — production-сервер на порту 3000.

В Docker frontend доступен на http://localhost:8080. Динамический SSR требует сервера Next.js; статическая раздача `dist` через Nginx здесь больше не используется.
